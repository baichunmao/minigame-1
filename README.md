# Minigame 1
## Devlog

Consider the scene as a complete stage setup of a theater waiting for a play. Here, every GameObject is an actor or prop on the stage: it can be a character, a chair, or a lamp. Actor, by itself, is only a vessel and does not have the capability to perform any action. Components are attributes or features assigned to actors/props. Movement Component allows actors to move, Light Component allows a lamp to illuminate, and Audio Component allows them to talk. All GameObjects reside in the Scene. Each GameObject has its behaviors defined by its Components. Without Components, GameObjects are empty entities, and without GameObjects, there will be no elements on the Scene stage.
